Exam details

Scoring is +1 for each correct answer and 0 for wrong, blank or double-marked answers. The printed sheet has 50 questions; use fewer if the paper has fewer.

Answer key

Tap the correct option for each question, or paste the whole key as letters (for example ABDCA BBCDA…; spaces and numbers are ignored). One key works for every language version of the sheet.

Merge places

Every name as written on the sheets, with how many people wrote it. Tick the ones that mean the same, then give the single name to rank them under. Capital letters and extra spaces are already ignored.
